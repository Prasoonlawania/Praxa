# Praxa

> Complete Real-Time Messaging Platform and Multimodal AI Workspace


## 📖 Description

**Praxa** is an intelligent, high-performance web communication platform that seamlessly combines real-time human-to-human messaging, peer-to-peer audio/video calling, and an integrated multimodal AI assistant powered by Google's Gemini models.

Designed with a distraction-free aesthetic and an adaptive universe theme engine, Praxa offers a unified workspace for messaging, media sharing, and AI-assisted productivity.

---

## ✨ Highlights

- **🤖 Multimodal AI Assistant**: Powered by Google Gemini 3.5 Flash for natural conversations, context-aware dialogue, and one-click chat summarization.
- **💬 Real-Time Messaging**: Instant direct and group communications with message starring, forwarding, deletion, and unread counters.
- **📹 Audio & Video Calling**: Built-in peer-to-peer WebRTC video and voice call functionality right inside chat rooms.
- **🎨 10 Universe Themes**: Tailored fandom and productivity visual skins including *Dark Workstation*, *Light Workstation*, *Money Heist*, *Spider-Man*, *Marvel*, *Avengers*, *Iron Man*, *JARVIS HUD*, *Asur*, and *House of the Dragon*.
- **🖼️ Custom Canvas Wallpapers**: Client-side image resizing and compression engine for custom background wallpapers.
- **📎 Media & File Sharing**: Seamless attachment handling for images, documents, audio, and video files backed by Firebase Cloud Storage.
- **🔒 Enterprise-Grade Security**: Document-level role-based access control with granular Firestore security rules and Firebase Authentication.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS v4, Lucide Icons, date-fns, react-markdown
- **Backend**: Node.js, Express, TSX, `@google/genai` SDK
- **Database & Storage**: Google Cloud Firestore, Firebase Auth, Firebase Storage
- **Build Tool**: Vite 5
